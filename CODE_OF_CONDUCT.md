# Community code of conduct

Treat contributors and users with respect. Welcome questions and different
experience levels, offer constructive technical feedback, and respect privacy.

Harassment, discrimination, threats, sexualized conduct, personal attacks, and
sharing another person's private information without permission are not welcome.
These expectations apply to this project's issues, pull requests, discussions,
and other community spaces.

Maintainers may edit or remove inappropriate content, close discussions, or
restrict participation to protect the community. Enforcement should consider
context, severity, and repeated behavior, and avoid disclosing private reports.

Report concerns privately to the repository owner through a contact channel
listed on their GitHub profile. If none is available, request a private contact
channel in an issue without identifying affected people or publishing details.
